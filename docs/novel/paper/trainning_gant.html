4. Machine Allocation Strategy

4.1 Allocation Principle

  1. BDD100K (หนักสุด) → ให้ rtx4090 + runpod5090 รับ (GPU เร็ว + VRAM เยอะ)
  2. KITTI / Cityscapes (เบา) → ให้ rase4070, ku4070 เติมช่องว่าง (แต่ละ job <1 h)
  3. Large models (RT-DETR-L, DINO-R50) → บังคับ rtx4090 / runpod5090
  4. Small/nano models → กระจายลง 4070 ทั้งคู่
  5. HSG-DETR pretrain → parallel บน rtx4090 (n) + runpod5090 (s) — วันที่ 1

4.2 Model-to-Machine Map

Machine Models (assigned) Jobs Est. wall-time
rase4070 YOLOv8n, YOLOv10n, YOLOv26n, Mamba-YOLO tiny 4 × 5 = 20 ~57 h
ku4070 YOLOv8s, YOLOv10s, YOLOv26s, Mamba-YOLO base 4 × 5 = 20 ~83 h
rtx4090 HSG-DETR-n pretrain, HSG-DETR-n (5 ft), HSG-DETR-s (5 ft), RT-DETR-L (5 ft) 1 + 15 = 16 ~12 + 7 + 10 + 21 = ~50 h
runpod5090 HSG-DETR-s pretrain, DINO-R50 (5 ft) 1 + 5 = 6 ~13 + 16 = ~29 h

Total: 62 jobs, ~219 h wall-time distributed.

Load balancing: ku4070 มี 83 h > rase4070 57 h — ถ้าเครื่อง rase4070 เสร็จก่อน day 4 สามารถ takeover Mamba-YOLO base ได้

8. Risk & Contingency Plan

Risk Probability Impact Mitigation
HSG-DETR pretrain ไม่ converge Medium HIGH (delays 10 ft jobs) (1) Run smoke test 10-epoch on Day 0 night. (2) Start rtx4090 pretrain 6 h before runpod5090 — ให้เห็น curve ก่อน scale up
RT-DETR-L / DINO-R50 OOM บน 4090 Low Medium batch=4 + grad accumulation; ถ้ายัง OOM → ย้ายไป runpod5090 (32GB) → extend runpod rental 1 day
BDD100K download ช้า Medium Medium Pre-download on Day 0 (before official Day 1) ที่ทุกเครื่อง parallel
4070 walltime เกิน budget Low Low ตัด duplicate scale (ถ้า YOLOv26 ~ YOLOv8 ผลเท่ากัน ตัด 1) หรือลด epochs จาก 150 → 120
RunPod instance preempt Low HIGH (1) Save checkpoint ทุก 5 epochs. (2) Auto-resume script. (3) DINO-R50 BDD เป็น job สุดท้าย (resumable)
Training NaN (จาก bug ที่เคยเจอ) Low (patched) HIGH ใช้ commit ล่าสุด c34a05c ที่มี _finite_or_zero sanitization แล้ว
Dataset class mismatch (80 vs dataset classes) Medium Medium Standardize ทุก dataset ให้ align กับ 8-class autonomous-driving taxonomy ก่อนเริ่ม

10. Quick Commands (reference)

10.1 Start a training job (MCP convention) 

# rtx4090: HSG-DETR-n pretrain on COCO
python -m hsg_detr.train \
    --cfg backend/hsg_detr/configs/hsg_detr_n.yaml \
    --data coco.yaml \
    --imgsz 1280 --epochs 300 --batch 16 \
    --device 0 --name hsg_n_coco_pretrain

10.2 Fine-tune from COCO-pretrained checkpoint 

# rase4070: YOLOv8n fine-tune on IDD @ 640
yolo detect train model=yolov8n.pt data=idd.yaml \
    imgsz=640 epochs=150 batch=16 amp=true \
    project=runs/idd name=yolov8n_idd_640

10.3 Monitor all machines 

# from laptop
python scripts/training_summary.py --machines rase4070,ku4070,rtx4090,runpod5090
